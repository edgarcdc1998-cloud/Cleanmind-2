CAUSA RAIZ
- O GitHub Actions falhava no build de release/debug (`:app:validateSigningDebug`)
  com o erro:
  `Keystore file 'debug.keystore' not found for signing config 'debugConfig'.`
  Isso ocorria porque o arquivo `debug.keystore.base64` estava presente no repositório,
  mas o arquivo binário `debug.keystore` não era decodificado/gerado antes da execução
  das tarefas do Gradle no fluxo do GitHub Actions (`android-ci.yml`).

--------------------------------------------------------------------------------
CORREÇÃO
- Arquivos alterados:
  - .github/workflows/android-ci.yml
- Alterações realizadas:
  - Adicionada uma etapa no workflow do GitHub Actions para decodificar o arquivo
    `debug.keystore.base64` em `debug.keystore` utilizando o comando `base64 -d`:
    ```yaml
    - name: Decode debug keystore
      run: base64 -d debug.keystore.base64 > debug.keystore
    ```
- Por que a alteração preserva o comportamento real do aplicativo:
  - Nenhuma regra de negócio, código-fonte Kotlin ou configuração de produção foi
  alterada. Apenas disponibilizou-se o arquivo de chave de assinatura de debug
  necessário para a assinatura do APK no ambiente CI/CD, conforme exigido pelas
  configurações existentes em `app/build.gradle.kts`.
