CAUSA RAIZ
- Os arquivos de teste utilizavam a anotação @Config(sdk = [36]), forçando o
  Robolectric a inicializar o ambiente simulado com a API 36 (Android 16).
  Como a versão atual do Robolectric no classpath do projeto não possui suporte
  nativo ou artefatos offline embutidos para a API 36, o provedor de SDK do
  Robolectric (DefaultSdkProvider) lançava uma UnsupportedOperationException.
  Ao ajustar a anotação de configuração de teste para @Config(sdk = [34]) (Android 14),
  que é totalmente suportada e nativamente integrada ao ecossistema Robolectric,
  o ambiente de teste executa sem falhas.
